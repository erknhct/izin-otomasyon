# Senior UI/UX Web Design & Animation Skill

This skill enforces senior-level UI/UX aesthetics, modern design tokens, interactive micro-animations, and glassmorphic visual excellence for web application interfaces built with HTML, CSS, JavaScript, React, or Vue.

## Core Design Principles

### 1. Color System & Design Tokens
- **Theme Palettes**: Use curated Slate/Zinc HSL variables for dark/light themes (`--bg-main`, `--bg-card`, `--bg-sidebar`, `--border-color`, `--accent-primary`).
- **Subtle Borders**: Always use crisp sub-pixel borders (`1px solid rgba(255, 255, 255, 0.1)`) instead of heavy outlines.
- **Typography**: Modern font stack (`'Inter', system-ui, sans-serif`), tight letter-spacing on headings (`letter-spacing: -0.02em`), uppercase label tracking (`letter-spacing: 0.05em`).

### 2. Glassmorphism & Visual Depth
- **Elevated Surfaces**: Multi-layered container cards with backdrop blur filters (`backdrop-filter: blur(16px)`).
- **Ambient Lighting**: Radial ambient background glows (`radial-gradient`) providing high-tech 3D depth.
- **Top Accent Borders**: Interactive cards with gradient accent bars (`linear-gradient(90deg, #6366f1, #a855f7)`).

### 3. Micro-Animations & Motion Physics
- **Hover Lifts**: Cards and interactive panels smoothly lift on hover (`transform: translateY(-4px)`).
- **Icon Elasticity**: Nav icons scale and rotate slightly on hover (`transform: scale(1.15) rotate(5deg)`).
- **Button Feedback**: Tactile click feedback with active scaling (`transform: scale(0.96)`).
- **Page Transitions**: Smooth slide-and-scale entrance animations (`cubic-bezier(0.16, 1, 0.3, 1)`).

### 4. Interactive Component Rules
- **Form Controls**: Glowing focus rings (`box-shadow: 0 0 0 2px var(--bg-main), 0 0 0 4px var(--ring-color)`).
- **Badges**: Pill-shaped badges with subtle background opacity (`rgba(..., 0.15)`) and bold status text.
- **Data Tables**: Distinct uppercase headers, alternating hover highlights, and smooth row transitions.
